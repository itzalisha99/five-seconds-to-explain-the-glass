The one sentence a house cat would say in its own defence in the five
seconds after knocking a glass off the table — no apology, no confession,
just the most convincing case a cat can make for itself:

> That glass owed me rent for squatting on my table all week, so I evicted it.

## How it works

`main.py` (Python standard library only) writes the sentence to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Before writing,
it checks the entry against the bounty gate — 1–200 characters, not only
white space, a single sentence — and after writing it reads the file back
to prove it is byte-identical to the entry.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
